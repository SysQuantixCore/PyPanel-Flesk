# PyPanel Flask

[English](README.md) | [Português-BR](README.pt-BR.md)

Um painel administrativo leve, desenvolvido com Python e Flask, com interface moderna, rotas organizadas e estrutura modular para gerenciamento de páginas e funcionalidades.

## ✨ Recursos

- Interface moderna de painel administrativo
- Sistema de rotas baseado em Flask
- Arquitetura modular e organizada
- Templates HTML
- Arquivos estáticos CSS e JavaScript
- Fácil personalização e manutenção
- Compatibilidade com Python 3+

## 🛠️ Tecnologias

- Python 3+
- Flask
- HTML5
- CSS3
- JavaScript
