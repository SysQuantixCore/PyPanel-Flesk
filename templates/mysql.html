Instalar serviço MySQL no Windows

Se o MySQL já estiver instalado no computador, mas não aparecer como serviço do Windows, siga as etapas abaixo para registrá-lo.

1. Abra o PowerShell como administrador

  1. Abra o menu Iniciar do Windows.
  2. Pesquise por PowerShell.
  3. Clique com o botão direito e selecione Executar como administrador.

2. Localize o executável mysqld.exe

Execute o comando abaixo para verificar se o MySQL está disponível no PATH:

where.exe mysqld

Se o comando não encontrar o arquivo, localize a pasta de instalação. Um caminho comum é: 

C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqld.exe

3. Registre o serviço MySQL

Ajuste o caminho do executável conforme a instalação do seu computador e execute: 

& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqld.exe" --install MySQL80

4. Inicie o serviço

Start-Service MySQL80

5. Verifique o status

Get-Service MySQL80

Se o serviço estiver funcionando, o status deverá aparecer como Running.

6. Configure a inicialização automática

Set-Service MySQL80 -StartupType Automatic
Atenção: Este procedimento registra um serviço do Windows para uma instalação existente do MySQL. Ele não instala o servidor MySQL, não cria o diretório de dados e não configura a senha do usuário root. Se o serviço já estiver registrado, não execute novamente o comando --install. O nome MySQL80 deve corresponder ao nome configurado no backend Flask.
