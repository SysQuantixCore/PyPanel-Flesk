Configurar autenticação OAuth do Google Drive

Esta mensagem aparece porque o PyPanel ainda não possui uma sessão OAuth válida. Siga as etapas abaixo para preparar a integração com o Google Drive.

1. Acesse o Google Cloud Console

  1. Entre em Google Cloud Console.
  2. Crie um projeto ou selecione um projeto existente.
  3. Confirme que está trabalhando no projeto correto antes de configurar a API.

2. Ative a Google Drive API

  1. No menu do Google Cloud Console, abra APIs e serviços.
  2. Acesse Biblioteca, procure por Google Drive API.
  3. Abra a API e clique em Ativar.

3. Configure a tela de consentimento OAuth

  1. Em APIs e serviços, abra Tela de consentimento OAuth.
  2. Selecione o tipo de público adequado ao seu uso (interno ou externo, conforme sua conta e projeto).
  3. Informe o nome do aplicativo e o e-mail de suporte solicitado.
  4. Durante os testes, adicione sua conta Google como usuário de teste, se o Google solicitar.
  5. Configure o escopo do Google Drive necessário para a função de backup.

4. Crie as credenciais OAuth

  1. Abra APIs e serviços → Credenciais.
  2. Clique em Criar credenciais → ID do cliente OAuth.
  3. Selecione Aplicativo da Web.
  4. Cadastre a origem JavaScript e o URI de redirecionamento autorizados conforme os endereços usados pelo seu Flask.
  5. Copie o ID do cliente e o segredo do cliente para a configuração segura do backend.

5. Configure o Flask

O backend precisa implementar o fluxo OAuth: redirecionar para o Google, receber o retorno (callback), validar a resposta e armazenar os tokens com segurança. Configure no ambiente do servidor os valores fornecidos pelo Google, por exemplo: 

GOOGLE_CLIENT_ID=seu_client_id
GOOGLE_CLIENT_SECRET=seu_client_secret
GOOGLE_REDIRECT_URI=http://127.0.0.1:5000/google_callback

O endereço /google_callback é apenas um exemplo. Ele deve corresponder exatamente à rota de retorno implementada no seu Flask e ao URI cadastrado no Google Cloud Console.

6. Reinicie o PyPanel e teste

  1. Reinicie o servidor Flask após configurar as credenciais.
  2. Use Google Drive → Connect para iniciar a autorização.
  3. Conclua a autorização na página do Google e retorne ao PyPanel.
  4. Use Google Drive → Status para verificar a conexão.
Importante: Este tutorial prepara a configuração no Google Cloud, mas não implementa OAuth automaticamente. As rotas Flask /google_connect, /google_status e a rota de callback precisam executar o fluxo OAuth real. Não coloque o segredo do cliente diretamente no HTML ou JavaScript, nem publique esse valor no repositório.
