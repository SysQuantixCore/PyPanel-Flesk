# PyPanel-Flesk

## 📌 Sobre o projeto
O **PyPanel-Flesk** é um painel de controle web desenvolvido em Python utilizando Flask.  
Ele simula um ambiente de gerenciamento local, semelhante ao XAMPP, permitindo controlar serviços, arquivos e aplicações pelo navegador.

---

## 🚀 Funcionalidades
- ▶️ Start/Stop de serviços (ex: MySQL)
- 📁 Gerenciador de arquivos (upload, delete, navegação)
- 🔐 Sistema de login
- 📊 Monitoramento de status
- 🌐 Interface web simples

---

## 🧰 Tecnologias
- Python
- Flask
- MySQL
- HTML / CSS / JavaScript

---

## ⚙️ Como executar

```bash
git clone https://github.com/seu-usuario/PyPanel-Flesk.git
cd PyPanel-Flesk
pip install -r requirements.txt
python app.py

Acesse:

http://localhost:5000
